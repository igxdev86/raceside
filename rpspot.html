Signals the mark is what this race takes to win; signals read each horse's last six against it

AT THE MARK = has run within 2lb of the mark in its last three. CONSISTENT IMPROVER = every run in the last four within 3lb of the one before, no single leap over 10lb in the last two steps, net climbing, best two figures the two most recent. BOUNCE-BACK = has run the mark at least twice, last run 3–9lb below it. DECLINING = last run 10lb+ below its best, or two runs down in a row. The score ranks the evidence, not the price.
