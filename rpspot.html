One-tap copy on iPhone (set up once)
A Safari bookmark that copies the whole page in one tap, so you never select-all again.
  1. Tap COPY BOOKMARK CODE below.
  2. In Safari, on any page: Share → Add Bookmark → name it COPY PAGE → Save.
  3. Open Bookmarks → Edit → tap COPY PAGE → delete the address and paste the code → Done.
  4. From now on: on a Racing Post page tap Bookmarks → COPY PAGE. It says “copied”. Open Spotlight, tap PASTE.

AT THE MARK = within 2lb of the mark in its last three. IMPROVER = every run within 3lb of the one before, no leap over 10lb, climbing, best two the two most recent.
